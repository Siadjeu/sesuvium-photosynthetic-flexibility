# Photosynthesis-family evidence freeze v1.0.0

Frozen evidence date: **18 October 2026**. This is an evidence-reporting release, not a declaration that all family definitions, models or C4/CAM functions are resolved.

## Start here

- `docs/methods.md`: main-manuscript methods plus supplementary methodological detail.
- `docs/results.md`: results text and suggested table legends.
- `tables/Wang_family_counts_and_gene_lists.xlsx`: human-readable counts and gene-list workbook.
- `tables/generated/counts_supported.tsv`: Wang-layout supported-count table (eight datasets × 23 families).
- `tables/generated/gene_list_supported.tsv`: 657 supported family–locus records.
- `tables/generated/gene_list_all_evidence.tsv`: all 3,193 records, including caveats and exclusions.
- `tables/generated/id_lists/`: gene/protein ID lists separated by evidence tier, family and species.
- `inputs/`: final integrated ledger and reporting-closure records.
- `archive/scripts/`: available historical Step25kz17 validation scripts.
- `archive/checkpoints/`: available checkpoint tables, reports, QC, provenance and selected final core trees/alignments. Large TSVs are gzip-compressed.
- `provenance/source_inventory.tsv`: exact source and released hashes, with redaction/compression recorded.

## Interpretation

Count one locus per family and species. Do not sum across families as a unique gene total. The primary set is SUPPORTED; MODEL_CAVEAT (71 records) and LIMITED_PANEL_CAVEAT (285 records) remain separate. PARTIAL (99), UNRESOLVED (627), OUTSIDE_FAMILY_SET (1,414) and EXCLUDED (40) are not added to primary counts. MEP and PPA remain NA. A zero means no records in that tier, not genomic absence. Formal exhaustive Wang-equivalent counts and C4/CAM-specific function remain unestablished. Taxon/assembly labels must be resolved from the input manifest before manuscript submission; AT is A. tricolor, not A. thaliana.

## Verify and reproduce

From this release directory:

```bash
python3 scripts/verify_freeze.py
python3 scripts/build_family_tables.py --out ../family_tables_rebuilt
(cd ../family_tables_rebuilt && sha256sum -c SHA256SUMS.txt)
```

The output directory must be new. Python 3 is the only dependency for the reporting step. Source-ledger and source-matrix hashes are checked before output creation. All count tiers, unique locus keys and supported matrix cells are verified. The generated TSVs and ID lists are deterministic. The workbook is a static presentation artifact and is not regenerated by this script.

Optional short SLURM job, from a clone on the cluster:

```bash
export FREEZE_ROOT="$PWD/releases/photosynthesis_family_evidence_v1_2026-10-18"
export OUTPUT_DIR="$PWD/family_tables_rebuilt_${USER}_$(date -u +%Y%m%dT%H%M%SZ)"
sbatch --export=ALL,FREEZE_ROOT="$FREEZE_ROOT",OUTPUT_DIR="$OUTPUT_DIR" \
  "$FREEZE_ROOT/scripts/rebuild_tables.slurm"
```

No new search, alignment, tree or gene-model repair is required to regenerate these tables.

## Reproducibility boundaries

The package preserves the locally available checkpoint evidence, not every original HPC file. Full genomes, corrected proteome, complete reference databases, read data, all binary software/checkpoints and all upstream raw search outputs are not guaranteed to be included. Their available paths, hashes, commands and source provenance remain in the archived reports. Historical scripts are not a replacement for recovering those inputs. Archived source paths were anonymized; original source hashes identify the unredacted artifacts. This snapshot does not alter the older PEPC files already in the repository; use the integrated ledger here for current family counts.
