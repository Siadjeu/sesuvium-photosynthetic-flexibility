Tree comparison and review figures only; no inference rerun or final gene-count decision.
SVG files are vector figures readable in a browser or Inkscape. Supports are written for every internal branch.
Split comparison is unrooted and uses full sequence identifiers, never only the safe T labels.
RF comparisons are restricted to matching tip sets: main full/core and domain full/core. No direct RF between different tip sets is reported.
Exact split absence does not establish a strongly supported conflict. Identical-sequence branching and near-zero edges remain unresolved.
Rectangular tree orientation is for display only; no outgroup or biological root is inferred.
AT domain fragments remain one locus. The 45-locus tree set is not a final family census.
